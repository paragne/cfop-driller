Dense, fast, high-contrast. This is a drilling tool used with a cube in one hand, not a marketing page.

    Dark background, near-black. The cube renders bright against it.
    One accent color, used only for the primary action. Everything else is grayscale, except the home stats, whose rows run through the rainbow so the sets tell apart.
    System font stack. No web fonts, no font loading.
    Sharp or minimally rounded corners. No shadows, no gradients, no glass effects, no animated transitions except where they convey state change.
    The case picture is the largest element on screen by a wide margin. Everything else is chrome.
    Primary actions sit in the lower third, reachable by thumb on a phone.
    No modal dialogs. Notes edit in place.
    Design mobile-first, single column, then let it breathe on desktop. Do not design a desktop layout and shrink it.
